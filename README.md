# asana-rs

A Rust client for [Asana's REST API](https://developers.asana.com/reference/rest-api-reference),
generated from Asana's OpenAPI specification with a hand-written ergonomic layer on top, and
first-class support for webhooks.

> Work in progress. The crates are not yet published.
